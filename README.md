# ピッキング管理アプリ

倉庫のピッキング作業向けの、荷物チェックリスト管理アプリです。単一のHTMLファイルのみで動作し、ビルドや外部依存はありません。

## 特徴

- CSVによる荷物リストの一括取込（品名・数量）
- 「セット」機能: 複数商品をまとめて登録し、タブから選ぶだけで一括チェックリスト化
- タブ単位で並行して進捗管理（同じセットを複数のお客様向けに同時進行できます）
- 未完了の項目を上に自動ソート
- タブの色分け・備考（お客様名など）の入力
- 完了 / 残数 / 数量の集計、検索・絞り込み
- 履歴（アーカイブ）・ゴミ箱（誤削除の復元）
- JSONファイルによるバックアップの書き出し・読み込み（端末間の手動同期用）
- データはすべて端末内のブラウザ（localStorage）に保存され、外部には送信されません

## 使い方

`index.html` をブラウザで開くだけで動作します。GitHub Pagesで公開している場合は、そのURLをスマートフォンのブラウザで開き、「ホーム画面に追加」するとアプリのように利用できます。

## 技術構成

HTML / CSS / JavaScript のみで構成された単一ファイルです。外部ライブラリやサーバーサイド処理は使用していません。
